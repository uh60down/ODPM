# Project Management Examples

Applied ODPM examples for the domain of software product and project **delivery** — the work of building any product.

## Available

- [Project Management Domain Ontology](ontology.md) — Stories, Bugs, Sprints, Epics, and Releases modeled with the five building blocks, as a specialization of the generic project ontology. Built *with* ODPM, not part of it.

## The layering

- **Base (ODPM):** the five building blocks, the method, and the project invariants — domain-independent.
- **Domain (here):** Story / Bug / Sprint / Epic as instances of those blocks — specific to delivery.

The [banking](../banking/) examples model a *product* world; these model the *delivery* world that builds one.
